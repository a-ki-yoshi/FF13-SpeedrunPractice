FINAL FANTASY XIII のPC版(Steam版)にてRTAを練習しやすくするための機能を搭載したModです。

## 動作環境

- Windows
- Steam(PC)版FINAL FANTASY XIII
  - リージョンは問わない見込みですが、未確認です。  
    (日本版と海外版はexeが同一で、本Modが触るのはメモリ上のexeとセーブファイルのみ。)  
    ゲームが日本語であればModの表示も日本語、それ以外の言語では英語になります。  
    開発・動作確認は日本版で行っています。海外版での動作報告は歓迎します。

## 使い方

1. zipファイルをダウンロードする

[**こちらのページの`FF13-SpeedrunPractice-x.x.x.zip`をクリックしてください**](https://github.com/a-ki-yoshi/FF13-SpeedrunPractice/releases)。

2. zipファイルを展開し、`LICENSE`と`README`以外の4つのファイルを`ffXiiiimg.exe`と同じフォルダ内に置く

フォルダのパスの例: `C:\Program Files (x86)\Steam\steamapps\common\FINAL FANTASY XIII\white_data\prog\win\bin\`

  [FPSFix](https://github.com/MrTyton/Final-Fantasy-Speedruns/tree/master/Final%20Fantasy%20XIII/FPS%20Fix)や[FF13Fix-4GB](https://github.com/a-ki-yoshi/FF13Fix-4GB)と併用可能です。

| ファイル名| 説明 | 
| ---- | ---- |
| `dinput8.dll` | Mod本体 |
| `ff13-srpractice.ini` | メモ帳などのエディターで編集可能な設定ファイル。既定値を変更しないなら削除OK |
| `ff13-practice.bat` | Modありで起動するためのバッチファイル。詳細は「計測時の注意事項」にて |
| `ff13-run.bat` | Modなしで起動するためのバッチファイル。詳細は「計測時の注意事項」にて |

3. ゲームを起動する

4. 各種機能をホットキー入力で使用する(F1キーで各機能の説明を表示)

※更新する(別のバージョンを導入し直す)場合は、iniファイルの差し替えは、基本的には不要です。ただし、Releasesページで確認できるバージョンごとの更新内容にiniファイルの変更に関する内容が記載されていることはありうるので、それは確認しておいてください。

## 計測時の注意事項

Speedrun.com において、ゲームやカテゴリー別に許可されていないModの使用は禁止のルールとなっています。  
Speedrun.comなどに提出するためのタイム計測時には、このツール(Mod)のどの機能も使用しないでください。  
特に、「戦闘オーバーレイ」はONにしていても戦闘時にしか表示されないので、注意が必要です。  
左上に何も文字が表示されておらず、ホットキーが押されていない状態であれば、Modなしと同等の状態になります。

### 計測などの時にはMod自体を使えないようにしたい場合

同梱の2つのbatファイル(バッチファイル)を実行する形でゲームを起動すると、スムーズです。  
`ff13-run.bat`: ModなしでFF13を起動  
`ff13-practice.bat`: ModありでFF13を起動  
- `dinput8.dll` のファイル名を無効なファイル名(`dinput8.dll.off`)に変更したり戻したりすることで、Modの有効/無効の切り替えを実現しています
- batファイルを使わなくても、手作業でdllファイルを退避やファイル名変更などしたり、従来のショートカットアイコンをクリックしても、正常に起動することができます
- batファイルは、ショートカットを作成してそちらをクリックする形式でも実行可能です
- batファイル名は、拡張子部分以外は変更可能です

## ホットキー概要

- 各機能にはホットキーが割り当てられています
- F1キーで、各機能と現在のホットキーの一覧をゲーム画面に表示できます
- 既定の設定では、ゲームのウィンドウがアクティブなときだけ有効です
- iniファイルにて `require_focus = 0` を設定すると、アクティブでないときも有効にできます

## 機能

いずれの機能も、ホットキーを押さなければすべてOFFの状態です。

ON/OFF切り替えするタイプの機能は、ゲーム再起動後もON/OFFの設定が引き継がれます。

- **ホットキー一覧表示** — `help`
  - ホットキー: F1
  - 各機能と現在のホットキーの一覧を表示する。もう一度押すと閉じる
  - iniファイルでホットキーを変更した場合は、変更後のキーが表示される

- **ゲーム速度変更** — `game_speed`
  - ホットキー: F2
  - ゲームスピードを変更する。フィールド移動、戦闘、ATB速度など全体的に変わる
  - ゲームスピードの初期値: 3.0
  - iniファイルにて、0.1~10.0 に変更可能
  - iniファイルにて`2.0,3.0`などのように複数設定も可能。ホットキーで2.0倍→3.0倍→OFFのように順番に切り替わる

- **KILLモード** — `kill_mode`
  - ホットキー: F3
  - ホットキーで「戦闘開始時に即勝利 + 一撃必殺」→「一撃必殺」→OFFの順番に切り替えることができる
    - **戦闘開始時に即勝利**
      - 戦闘中にONにしても、既に始まっている戦闘には効かない。次の戦闘開始時から有効
      - 戦闘が始まると同時に勝利で終わる
      - アイテムは、確定ドロップのもの以外はドロップしない
    - **一撃必殺**
      - ダメージを与えた瞬間にその敵のHPが0になる
      - アイテムのドロップ仕様は、通常の戦闘と同じ
      - **ONのまま召喚はしないでください** — 通常の敵に対してしか検証していないため。召喚する前にOFFにしてください

- **ワープ** — `warp`
  - ホットキー: F4
  - 地点を記録して、瞬時にそこへ戻る
  - 敵避けの練習の効率化に使えます
    - 敵避け対象の領域の手前で記録→敵避けを実行→成功したらワープ→敵にぶつかって状態をリセット など([参考動画](https://youtu.be/o15w01uMevo?si=1GawKC-p5130JfWZ&t=4))
  - ホットキーを**長押し**で現在地を確認なしで記録する
  - フィールド上でホットキーを**短く2回押す**とこのゾーンの記録地点へワープする
  - 地点はゾーンごとに1つずつ記録できる
  - 記録はゲーム再起動後も有効
  - 移動先が遠かったりするとマップやオブジェクトなどが読み込まれないことがあります

- **セーブデータロード時の敵の出現を抑止** — `enemy_suppress`
  - ホットキー: F5
  - セーブデータのロード完了後にフィールドの敵グループが配置されなくなる
  - セーブデータのロード完了後にONにしても効かない。次のロード時から有効
  - ロード後に移動すると、別のマップがロードされて敵が出現しうる

- **どこでもセーブ** — `save`
  - ホットキー: F7
  - **この機能を使う場合は、クラウド同期をOFFにしてください。クラウド同期ONの状態は動作未確認です**
  - セーブポイント以外でのセーブが可能
  - そのセーブをロードすると、セーブした地点から始まる
  - フィールド移動中のみ可能
  - セーブ一覧画面では、この機能を使ったセーブは番号の後ろに印が付く
    - 既定値: *
    - iniファイルの`[save] list_mark`にて、印のテキストを編集可能(最大8文字、全角文字も可。数字は使えない)
      - ゲームのフォントが持っていない文字は空白として表示される。設定したら一覧で実際の表示を確認すること
  - セーブ地点によっては、オブジェクトや近くの敵がロードされません
  - セーブ地点によっては、ロード後に進行不能になります
  - DLLファイルまたは`ff13-mods\ff13-srpractice_slots.dat`ファイルを退避か削除すると、近くのセーブポイントへのロードになります
  - セーブデータの保存先パスが通常と異なる場合は、iniファイルの`save_dir`にパスを入力してください

- **カメラ固定解除** — `camera_unstick`
  - ホットキー: F8
  - カメラをリーダー追従状態にする機能
  - どこでもセーブ機能のセーブデータをロード後、移動中にカメラが固定されてしまうことがある事象の対策用

- **セーブデータの整理** — `save_tidy`
  - ホットキー
    - メニューを開く/閉じる: F9
    - 選択中の項目を決定: Enter(`menu_ok`) または F9長押し
      - このメニュー表示中はキーボード入力で従来のゲーム操作をできないようにしているので、ゲームの決定キーと重なっていても安全
      - iniで`menu_ok`の値を空にすると長押しのみで決定可能
    - 項目を選ぶ: ↑ ↓キー
    - セーブ一覧で操作対象のセーブを選ぶ: A Dキー(`list_prev` / `list_next`)
      - このメニュー表示中はキーボード入力で従来のゲーム操作をできないようにしているが、ここで設定されたキーでカーソル操作が可能
    - テキスト入力: 各種キー
    - テキスト文字削除: Backspace
  - **このゲームのSteamクラウド同期OFF設定時のみ使えます。**
  - タイトル画面(およびデモ映像再生中の画面)と、セーブデータ一覧でのみメニューを表示する
  - それぞれの画面で表示されるメニューは異なる
  - 基本的にEnter(またはホットキー長押し)で決定
  - タイトル画面で使える機能
    - セーブデータ一覧に表示する範囲
      - ロード用のセーブ一覧で表示する章のフィルター
      - 指定した章のセーブだけをゲームのセーブ一覧に出す
      - この行を決定してもフィルターをリセットし、すべての章を表示することができる
      - セーブデータの移動もリネームもしない
      - ゲーム中のセーブ画面には効かない
      - 設定は保存されるので、次に起動したときも同じ章のままになる(その章のセーブが1件も無くなっていたときは、全件表示に戻る)
    - カテゴリー管理
      - セーブデータの一式をフォルダ単位で切り替える機能
        - 使用中のカテゴリーはこれまでどおりセーブフォルダ直下にあり、それ以外は`{セーブフォルダ}\categories\{カテゴリー名}\`に退避される
      - 未使用だと、「main」という名前のカテゴリーを選択中の状態として扱われる
      - 1カテゴリーにつき99のセーブデータを作成できる
      - 詳細な機能
        - 「使用中: {カテゴリー名}」
          - ←→キーを押して切替先を選び、決定で切替
        - 新しいカテゴリーを作って切替 (最新の1件をコピー / 全件コピー)
          - カテゴリー名を入力し、新カテゴリーへ切り替える
          - 「最新の1件をコピー」: 最新のセーブ1件だけをコピーする
            - コピーするのは、一覧が空だとタイトル画面からロードを選択できなくなるのを防止するため
            - 不要であれば、通常どおりセーブ一覧から削除可能
          - 「全件コピー」: 使用中のカテゴリーの全セーブをコピーする
          - 入力欄について
            - 半角文字はそのまま入力できる
            - 別の場所でコピーしておいたテキストをCtrl+Vで貼り付けることもできる
              - その場合は、全角、カナなどのマルチバイト文字も可
            - 最大24文字
            - `\ / : * ? " < > | ,`は使えない
            - Backspaceで1文字ずつ削除可能
            - 既存のカテゴリーと同じ名前は決定できない(入力欄に赤字でエラーが出る)
            - Enter(またはホットキー長押し)で決定、ホットキー短押しでキャンセル            
        - 使用中のカテゴリーの名前を変更
          - 「使用中:」にて選択中のカテゴリーの名前を変更できる
        - 「{カテゴリー名}」を削除
          - ←→キーを押して削除するカテゴリーを選び、決定で削除
          - セーブが1件以上あるカテゴリーは、確認のためもう一度決定が必要(8秒経つと確認は解除される)
          - 使用中のカテゴリーは選べない(消したいときは先に別のカテゴリーへ切り替える)
          - 中身ごとWindowsのごみ箱に入るので、間違えたときはごみ箱から戻せる
            - ごみ箱の無いドライブ(ネットワークやリムーバブル)にセーブフォルダを置いている場合は、そのまま削除される
      - どこでもセーブの管理ファイルや`.bak`(バックアップファイル)も、セーブデータと一緒に移動する
      - 切替中にクラッシュや電源断で中断された場合は、次回起動時に自動で完了する
    - 一覧の並べ替え
      - 使用中のカテゴリー内のセーブデータを 進行順(1章が先頭)/進行順(終盤が先頭)/セーブ番号順 に並べ替える
      - ゲームはファイルの更新日時で一覧を並べるため、この機能はファイルの日時を付け直すだけ
      - 一覧の日時表示は実際の保存日時のまま。各セーブ本来の日時を別ファイルに記録し、画面に出し直している
        - ファイルに実際に付く日時は、並べ替えを実行した日時(先頭がその時刻で、1行ごとに1分ずつ過去の日時)
        - Modを外した状態やエクスプローラーでは並べ替えを実行した日時が見える
      - 並べ替え後に作ったセーブは、再び並べ替え機能を実行しない限り、通常どおり先頭に出る
    - セーブ番号の振り直し
      - 使用中のカテゴリー内のセーブデータを ストーリー進行順(同一のデータは日時の順)に振り直す
      - リネーム中にクラッシュや電源断で中断された場合は、次回起動時に自動で完了するか、元の番号に戻す
  - セーブ一覧画面で使える機能(カーソルを合わせている項目ごとに利用可能)
    - メニューはそのカーソルに追従する: メニュー表示中もA/Dキーやコントローラーでカーソルを動かせて、
      どの行もカーソルが乗ったセーブへ切り替わる(タイトル行がその番号を出す)
    - メモ
      - テキストを入力し、ゲームのセーブ一覧に表示することができる
      - 「セーブデータ 05, チャプター 9 - text1」のように、1行目の末尾に付く
      - 入力欄について
        - 半角文字はそのまま入力できる
        - 別の場所でコピーしておいたテキストをCtrl+Vで貼り付けることもできる
          - その場合は、全角、カナなどのマルチバイト文字も可
        - 最大24文字
        - `,` は使えない
        - Backspaceで1文字ずつ削除
        - Enter(またはホットキー長押し)で決定、ホットキー短押しでキャンセル
      - セーブデータを上書き保存すると、メモも消える
      - ロード後のフィールドから表示するセーブ画面の「新規セーブデータを作成」の項目にはメモを付けられない
        - 作成後にセーブ一覧を開きなおしてからであれば入力できる
    - 別カテゴリーへ送る(「コピー」「移動」の行)
      - セーブデータ1件、または範囲選択した分をまとめて「コピー」または「移動」できる
      - ←→で送り先のカテゴリーを選ぶ。選んだ先は行に出る(「コピー → {カテゴリー名}」)
      - 「<新しいカテゴリー>」を選ぶと名前を付けて新規作成
      - 送り先ではそのカテゴリーの空き番号に入る(一覧の番号表示も書き換わる)
      - 送り先の空き番号が範囲の件数に足りないときは、何も送らずにその旨を表示する
      - 「移動」した後も、開いたままの一覧には元の行が残って見える
        - 選んでも「ロードに失敗しました」と出るだけで安全
        - 一覧を開き直すと消える
      - 「移動」で移動元のセーブデータが0件になった状態でタイトル画面に戻ると、「LOAD GAME」表示が消えるので注意
    - 範囲選択(複数のセーブデータをまとめて操作する)
      - 「範囲選択 (セーブデータNを始点にする)」を実行すると、そのセーブが範囲の一方の端になる
      - ゲームのカーソルをもう一方の端に合わせると(A/Dキーまたはコントローラー)、コピー・移動・削除の行が
        「コピー (一覧上のセーブN〜MのX件) → 送り先」の形に変わる
      - 対象は一覧の画面上の並びで両端を含む範囲(N・Mは両端のセーブ番号であって、間の番号全部ではない)。
        章フィルター使用中は、表示されている行だけが対象
      - 範囲の解除は同じ行(「範囲選択を解除」)でもう一度実行。並べ替え・フィルター変更・一覧画面を離れた時も自動で解除される
    - 削除
      - 範囲選択した分のセーブデータをまとめて削除する。1件だけ消すなら、ゲーム自身のセーブ一覧でEキーから削除できる
      - 範囲が未選択であれば、実行不可
      - 1回目の決定で行が「削除の確認: N件 — もう一度[Enter/長押し]で実行」に変わり、もう一度決定すると実行される
      - 確認は8秒で自動的に解除される。行から離れる・**カーソルを別のセーブへ動かす**・メニューを閉じる・
        範囲選択を解除したときも解除される
      - セーブデータは`.bak`ファイルと一緒にWindowsのごみ箱へ送られるので、間違えてもごみ箱から戻せる
        - ごみ箱の無いドライブ(ネットワークやリムーバブル)にセーブフォルダを置いている場合は、そのまま削除される
      - 開いたままの一覧には削除した行が残って見える。一覧を開き直すと消える
      - カテゴリー内のセーブデータが0件になると、「移動」の時と同じくタイトル画面から「LOAD GAME」表示が消えるので注意

- **戦闘オーバーレイ** — `battle_overlay`
  - ホットキー: F10
  - 戦闘中に下記を表示する
    - TIME
      - GAME: ゲーム内時間
      - REAL: 実時間
      - ATB \*\*s: オプティマチェンジで味方全員のATBが全回復するまでの残り秒数(READY = 次のチェンジで全回復する)
    - TARGET
      - HP: ターゲットの残りHP
      - ATB: ターゲットのATBゲージの値
      - CHAIN: ターゲットのチェーンゲージの持続時間。倍率が100%に戻るまでの残り秒数
  - 「ゲーム速度変更」機能も使用している場合は、ゲーム内時間も変動する

- **任意戦闘呼び出し** — `battle_picker`
  - ホットキー
    - メニューを開く/決定/閉じる: F11
    - メニュー移動: ↑ ↓ キー
    - メニューページ送り: ←→キー
  - フィールドに応じた戦闘シーンの一覧を表示し、選択すると戦闘に入る
  - ホットキーでメニューの開閉を切り替え、長押しで決定
  - メニューを閉じたまま長押しすると、最後に選択した戦闘(未選択の場合は一番上の戦闘)をすぐに始められる
  - 各種リザーブスモークを使ってから戦闘可能。たとえばスニークスモークを使うと、元から奇襲可能な戦闘であれば奇襲できる
  - 戦闘後、アイテムは減らず、TP・ライブラ値は元に戻る
  - ●が付いている戦闘は、Any%で必須の戦闘
  - △が付いている戦闘は、Any%で場合によっては実施する戦闘
  - 最後に実施した通常の戦闘と同一の戦闘の行には "here" と表示される
  - この機能は特に不安定な挙動が多いので、下記をご留意ください
    - **決定後は、できるだけ入力をしないことをお勧めします**。最悪スタックやクラッシュします
      - 特に危ないのはポーズメニュー(スタートボタン)です。決定から戦闘が表示されるまでの間に開くとクラッシュすることがあります。戦闘が画面に出るまでスタートボタンには触れないでください
    - 敵が足りない状態で戦闘が始まった場合は`btsc##### came up short -- pick it again`と表示されます。同じ戦闘をもう一度選び直せば直ります
    - 呼び出した戦闘は、その場のゲームスクリプトが想定している戦闘ではありません。ストーリー進行に影響しなかった実績はありますが、異常(消えないシンボル・宝箱・フラグなど)は起こりうる前提でご利用ください
    - 決定時にセーブポイントを調べる操作と重複した場合は、決定がキャンセルされます
    - **戦闘開始時の味方の向く方向は、フィールドでの向く方向に依存する場合があります**。今後対応できるか不明です
    - 戦闘シーンと居場所の組み合わせによっては、背景が正常に読み込まれません
    - 戦闘前後の読み込み時間がかなり長いことがあります
    - 戦闘後、立ち位置が移動したりマップが読み込まれなかったりBGMが通常と異なることがあります
    - 戦闘によっては、メンバーチェンジの処理が入ります
      - 戦闘後もメンバーチェンジ後の状態が持続します
      - 処理がない戦闘に対して「メンバーチェンジの処理を入れてほしい」などの場合は、ご連絡をお願いします
    - 都合上、戦闘によっては直前にカットシーンがあります
      - 一覧に "CS" と書いてある戦闘が該当します
      - 通常どおりスキップしてOKです
    - カットシーンがない戦闘の場合、**BGMの始まりが実際のタイミングとは異なることがあります**
      - iniファイルの`bgm_delay_ms`にて、BGMの開始タイミングをある程度調節可能です
      - 元々直前にカットシーンがある戦闘について「カットシーンを直前に入れてほしい」などの場合は、ご連絡をお願いします

## 自動生成されるファイルについて

- `ff13-mods\`フォルダーおよびその中の各種ファイル
  - 初回起動時に作成
- `{セーブデータのディレクトリ}\ff13-NN.dat.bak`
  - Modがチェックポイントを調整する直前に自動作成するセーブデータのバックアップ
  - 万一セーブがロードできなくなったら、`.bak`を`.dat`に名前を戻せば復旧できます

## 不具合やクラッシュが起きたとき

できれば、下記の対応をお願いします。

### 1. まずログを退避(コピー)してください

`ff13-mods\ff13-srpractice.log`を、デスクトップなど別の場所へコピーしてください。

> **注意: ゲームを再起動すると、このログは最初から書き直されます。**
> 再起動やゲームの終了をする前にコピーしてください(落ちた直後のログが唯一の手がかりです)。

### 2. 再現できる場合は`verbose`で再現させてください

`ff13-srpractice.ini`の`[log]`セクションを`level = verbose`に変更してからゲームを起動し、
同じ操作をして症状を再現させてください。verboseにするとゲーム内部の動きまで記録されるため、
原因の特定がぐっと早くなります。再現できたら、そのログも同じように退避してください。

### 3. ログを送っていただけると大変助かります

症状(何をしたら何が起きたか)と、退避したログを添えてご連絡くださると、大変助かります。

## アンインストール

- アンインストールはインストールフォルダから`dinput8.dll`を削除するだけ
- 自動生成されるファイルやディレクトリも削除で問題ありません
  - **例外: セーブフォルダの`categories\`フォルダには、使用中でないカテゴリーのセーブデータ本体が入っています。** 削除する前に、必要なセーブを`categories\`の外(セーブフォルダ直下)へ移すか、フォルダごとバックアップしてください
- 並べ替えを使った後にアンインストールすると、一覧の日時表示は「最後に並べ替えた日時」になります(上の説明どおり。セーブの中身は無事)
- そのままにしていても、ゲームに影響はありません
- どこでもセーブ機能で作成したデータは、ゲーム画面にて通常どおり削除も可能です

## 安全性

- このModは一切の通信を行わず、ネットワーク接続もしません
- ゲーム本来のファイルのうち、書き換えるファイルは、どこでもセーブ機能や整理機能を使って作成したセーブデータファイルのみです
