FINAL FANTASY XIII のPC版(Steam版)にてRTAを練習しやすくするための機能を搭載したModです。

## 動作環境

- Windows
- Steam(PC)版FINAL FANTASY XIII

## 使い方

1. zipファイルをダウンロードする

[**こちらのページの`FF13-SpeedrunPractice-x.x.x.zip`をクリックしてください**](https://github.com/a-ki-yoshi/FF13-SpeedrunPractice/releases)。

2. zipファイルを展開し、`LICENSE`と`README`以外の4つのファイルを`ffXiiiimg.exe`と同じフォルダ内に置く

フォルダのパスの例: `C:\Program Files (x86)\Steam\steamapps\common\FINAL FANTASY XIII\white_data\prog\win\bin\`

  [FPSFix](https://github.com/MrTyton/Final-Fantasy-Speedruns/tree/master/Final%20Fantasy%20XIII/FPS%20Fix)や[FF13Fix-4GB](https://github.com/a-ki-yoshi/FF13Fix-4GB)と併用可能です。

| ファイル名| 説明 | 
| ---- | ---- |
| `dinput8.dll` | Mod本体 |
| `ff13-srpractice.ini` | メモ帳などのエディターで編集可能な設定ファイル。既定値を変更しないなら削除OK |
| `ff13-practice.bat` | Modありで起動するためのバッチファイル。詳細は「計測時の注意事項」にて |
| `ff13-run.bat` | Modなしで起動するためのバッチファイル。詳細は「計測時の注意事項」にて |

3. ゲームを起動する

4. 各種機能をホットキー入力で使用する(F1キーで各機能の説明を表示)

※更新する(別のバージョンを導入し直す)場合は、iniファイルの差し替えは、基本的には不要です。ただし、Releasesページで確認できるバージョンごとの更新内容にiniファイルの変更に関する内容が記載されていることはありうるので、それは確認しておいてください。

## 計測時の注意事項

Speedrun.com において、ゲームやカテゴリー別に許可されていないModの使用は禁止のルールとなっています。

Speedrun.comなどに提出するためのタイム計測時には、このツール(Mod)のどの機能も使用しないでください。

特に、「戦闘オーバーレイ」はONにしていても戦闘時にしか表示されないので、注意が必要です。

左上に何も文字が表示されておらず、ホットキーが押されていない状態であれば、Modなしと同等の状態になります。

### 計測などの時にはMod自体を使えないようにしたい場合

同梱の2つのbatファイル(バッチファイル)を実行する形でゲームを起動すると、スムーズです。

`ff13-run.bat`: ModなしでFF13を起動

`ff13-practice.bat`: ModありでFF13を起動

- `dinput8.dll` のファイル名を無効なファイル名(`dinput8.dll.off`)に変更したり戻したりすることで、Modの有効/無効の切り替えを実現しています
- batファイルを使わなくても、手作業でdllファイルを退避やファイル名変更などしたり、従来のショートカットアイコンをクリックしても、正常に起動することができます
- batファイルは、ショートカットを作成してそちらをクリックする形式でも実行可能です
- batファイル名は、拡張子部分以外は変更可能です

## ホットキー概要

- 各機能にはホットキーが割り当てられています
- F1キーで、各機能と現在のホットキーの一覧をゲーム画面に表示できます
- 既定の設定では、ゲームのウィンドウがアクティブなときだけ有効です
- iniファイルにて `require_focus = 0` を設定すると、アクティブでないときも有効にできます

## 機能

いずれの機能も、ホットキーを押さなければすべてOFFの状態です。

ON/OFF切り替えするタイプの機能は、ゲーム再起動後もON/OFFの設定が引き継がれます。

- **ホットキー一覧表示** — `help`
  - ホットキー: F1
  - 各機能と現在のホットキーの一覧を表示する。もう一度押すと閉じる
  - iniファイルでホットキーを変更した場合は、変更後のキーが表示される

- **ゲーム速度変更** — `game_speed`
  - ホットキー: F2
  - ゲームスピードを変更する。フィールド移動、戦闘、ATB速度など全体的に変わる
  - ゲームスピードの初期値: 3.0
  - iniファイルにて、0.1~10.0 に変更可能
  - iniファイルにて`2.0,3.0`などのように複数設定も可能。ホットキーで2.0倍→3.0倍→OFFのように順番に切り替わる

- **KILLモード** — `kill_mode`
  - ホットキー: F3
  - ホットキーで「戦闘開始時に即勝利 + 一撃必殺」→「一撃必殺」→OFFの順番に切り替えることができる
    - **戦闘開始時に即勝利**
      - 戦闘中にONにしても、既に始まっている戦闘には効かない。次の戦闘開始時から有効
      - 戦闘が始まると同時に勝利で終わる
      - アイテムは、確定ドロップのもの以外はドロップしない
    - **一撃必殺**
      - ダメージを与えた瞬間にその敵のHPが0になる
      - アイテムのドロップ仕様は、通常の戦闘と同じ

- **ワープ** — `warp`
  - ホットキー: F4
  - 地点を記録して、瞬時にそこへ戻る
  - 敵避けの練習の効率化に使えます
    - 敵避け対象の領域の手前で記録→敵避けを実行→成功したらワープ→敵にぶつかって状態をリセット など([参考動画](https://youtu.be/o15w01uMevo?si=1GawKC-p5130JfWZ&t=4))
  - ホットキーを**長押し**で現在地を確認なしで記録する
  - フィールド上でホットキーを**短く2回押す**とこのゾーンの記録地点へワープする
  - 地点はゾーンごとに1つずつ記録できる
  - 記録はゲーム再起動後も有効
  - 移動先が遠かったりするとマップやオブジェクトなどが読み込まれないことがあります

- **セーブデータロード時の敵の出現を抑止** — `enemy_suppress`
  - ホットキー: F5
  - セーブデータのロード完了後にフィールドの敵グループが配置されなくなる
  - セーブデータのロード完了後にONにしても効かない。次のロード時から有効
  - ロード後に移動すると、別のマップがロードされて敵が出現しうる

- **どこでもセーブ** — `save`
  - ホットキー: F7
  - **この機能を使う場合は、クラウド同期をOFFにしてください**
  - セーブポイント以外でのセーブが可能
  - そのセーブをロードすると、セーブした地点から始まる
  - フィールド移動中のみ可能
  - セーブ一覧画面では、この機能を使ったセーブは番号の後ろに印が付く
    - 既定値: *
    - iniファイルの`[save] list_mark`にて、印のテキストを編集可能
  - セーブ地点によっては、オブジェクトや近くの敵がロードされません
  - セーブ地点によっては、ロード後に進行不能になります
  - DLLファイルまたは`ff13-mods\ff13-srpractice_slots.dat`ファイルを退避か削除すると、近くのセーブポイントへのロードになります
  - セーブデータの保存先パスが通常と異なる場合は、iniファイルの`save_dir`にパスを入力してください

- **カメラ固定解除** — `camera_unstick`
  - ホットキー: F8
  - カメラをリーダー追従状態にする機能
  - どこでもセーブ機能のセーブデータをロード後、移動中にカメラが固定されてしまうことがある事象の対策用

- **戦闘オーバーレイ** — `battle_overlay`
  - ホットキー: F10
  - 戦闘中に下記を表示する
    - GAME: ゲーム内時間
    - REAL: 実時間
    - HP: ターゲットにしている敵の残りHP
  - 「ゲーム速度変更」機能も使用している場合は、ゲーム内時間も変動します

- **任意戦闘呼び出し** — `battle_picker`
  - ホットキー
    - メニューを開く/決定/閉じる: F11
    - メニュー移動: ↑ ↓ キー
    - メニューページ送り: ←→キー
  - フィールドに応じた戦闘シーンの一覧を表示し、選択すると戦闘に入る
  - ホットキーでメニューの開閉を切り替え、長押しで決定
  - メニューを閉じたまま長押しすると、最後に選択した戦闘(未選択の場合は一番上の戦闘)をすぐに始められる
  - 戦闘後、アイテムは減らず、TP・ライブラ値は元に戻る
  - この機能は特に不安定な挙動が多いので、下記をご留意ください
    - **決定後は、できるだけ入力をしないことをお勧めします**。最悪スタックやクラッシュします
    - 決定時にセーブポイントを調べる操作と重複した場合は、決定がキャンセルされます
    - **戦闘開始時の味方の向く方向は、フィールドでの向く方向に依存する場合があります**。今後対応できるか不明です
    - 戦闘シーンと居場所の組み合わせによっては、背景が正常に読み込まれません
    - 戦闘前後の読み込み時間がかなり長いことがあります
    - 戦闘後、立ち位置が移動したりマップが読み込まれなかったりBGMが通常と異なることがあります
    - 戦闘によっては、メンバーチェンジの処理が入ります
      - 戦闘後もメンバーチェンジ後の状態が持続します
      - 処理がない戦闘に対して「メンバーチェンジの処理を入れてほしい」などの場合は、ご連絡をお願いします
    - 都合上、戦闘によっては直前にカットシーンがあります
      - 一覧に "CS" と書いてある戦闘が該当します
      - 通常どおりスキップしてOKです
    - カットシーンがない戦闘の場合、**BGMの始まりが実際のタイミングとは異なることがあります**
      - iniファイルの`bgm_delay_ms`にて、BGMの開始タイミングをある程度調節可能です
      - 元々直前にカットシーンがある戦闘について「カットシーンを直前に入れてほしい」などの場合は、ご連絡をお願いします

## 自動生成されるファイルについて

- `ff13-mods\`フォルダーおよびその中の各種ファイル
  - 初回起動時に作成
- `{セーブデータのディレクトリ}\ff13-NN.dat.bak`
  - Modがチェックポイントを調整する直前に自動作成するセーブデータのバックアップ
  - 万一セーブがロードできなくなったら、`.bak`を`.dat`に名前を戻せば復旧できます

## 不具合やクラッシュが起きたとき

できれば、下記の対応をお願いします。

### 1. まずログを退避(コピー)してください

`ff13-mods\ff13-srpractice.log`を、デスクトップなど別の場所へコピーしてください。

> **注意: ゲームを再起動すると、このログは最初から書き直されます。**
> 再起動やゲームの終了をする前にコピーしてください(落ちた直後のログが唯一の手がかりです)。

### 2. 再現できる場合は`verbose`で再現させてください

`ff13-srpractice.ini`の`[log]`セクションを`level = verbose`に変更してからゲームを起動し、
同じ操作をして症状を再現させてください。verboseにするとゲーム内部の動きまで記録されるため、
原因の特定がぐっと早くなります。再現できたら、そのログも同じように退避してください。

### 3. ログを送っていただけると大変助かります

症状(何をしたら何が起きたか)と、退避したログを添えてご連絡くださると、大変助かります。

## アンインストール

- アンインストールはインストールフォルダから`dinput8.dll`を削除するだけ
- 自動生成されるファイルやディレクトリも削除で問題ありません
- そのままにしていても、ゲームに影響はありません
- どこでもセーブ機能で作成したデータは、ゲーム画面にて通常どおり削除も可能です

## 安全性

- このModは一切の通信を行わず、ネットワーク接続もしません
- ゲーム本来のファイルのうち、書き換えるファイルは、どこでもセーブ機能を使って作成したファイルのみです
